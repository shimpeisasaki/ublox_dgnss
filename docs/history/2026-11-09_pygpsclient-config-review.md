# PyGPSClient設定書き込み機能のレビュー

2026-11-09。導入済みPyGPSClient 1.8.0 / pyubx2 1.4.1を対象にした。
F9P向けのModern UBX Configuration Interface（CFG-VALSET/GET/DEL）を中心に確認。
インストール済みコードの変更、受信機への接続、シリアル送信は行っていない。

## 指摘事項

### P2: 別コマンドへのACKでも書き込み成功表示になる

`ubx_config_dialog.py:155` の `update_pending()` は応答の `identity` でのみ
待機中の画面を選び、ACKの `clsID` / `msgID` を確認しない。
`ubx_cfgval_frame.py:474` は届いたACK-ACKで成功表示にする。
CFG-VALSETの応答待ちに、別のCFG-MSGに対するACKを渡すと、成功表示になり
待機状態が解除されることをオフラインで再現した。

対策案: 少なくともACK内の対象クラス・IDを照合する。同じCFG-VALSET間には
項目を識別する応答IDがないため、逐次送信し、対象キー・保存層の読み戻しで検証する。

### P2: 読み戻し応答に対象キーがなくても成功表示になり、古い値が残る

`ubx_cfgval_frame.py:463` の `update_status()` は、CFG-VALGETを受け取ると
キー・層の一致を確認する前に成功表示にする。対象キーが応答にない場合でも
元の値を消さず、GET受信成功の表示にする。
最低C/N₀を選択して30と表示した状態で、測位周期だけを含む応答を渡すと、
30の表示が残ったまま成功表示になることを再現した。

また、VALSET後の自動VALGETと期待値比較はない。手動でGET操作が必要。
対策案: 要求したキー・層を保持し、一致する応答のみ採用する。書き込み後には
VALGETによる値の一致を検証する。

### P2: DEFAULT・未選択でSETすると、暗黙にRAMへ書き込む

`ubx_cfgval_frame.py:181` のLayer選択にはRAM/BBR/FLASH/DEFAULTが常に並ぶ。
`_do_valset()`（同:346）はBBRとFLASH以外をすべてRAMとして扱う。
そのためDEFAULTや初期の空欄でもRAM向けVALSETが生成されることを再現した。
DEFAULTは読み出し用の層であり、SET操作で選べる表示は誤解を招く。

対策案: SETではRAM/BBR/FLASHのみ選択可能にし、未選択時は送信を拒否する。
FLASHだけの指定は保存層への書き込みであり、RAMにも同時に適用する指定ではない。

### P3: 符号付き整数の最大値検証が1大きい

`helpers.py:169` ではnビット符号付き整数を `-2^(n-1) <= x <= 2^(n-1)` と
判定し、本来の最大値 `2^(n-1)-1` を超える値を通す。
最低仰角（I1）に128を指定すると、入力検証を通過した後に`OverflowError`が発生する。
`_do_valset()`ではこの例外を捕捉しない。受信機には送られないが、入力エラーを
正常に案内できない。今回の候補値15では発生しない。

## 確認できた機能

- 送信ボタンからCFG-VALSETを生成し、送信キューを経由してシリアル等へ書く経路がある。
- RAM=1、BBR=2、FLASH=4のSET層指定は正しい。
- GET側のRAM=0、BBR=1、FLASH=2、DEFAULT=7の層指定も実装されている。
- 1回のGUI操作で1項目を設定する。トランザクション指定は0（なし）。
- 起動時の操作モードはGET。項目名・型・KeyIDはpyubx2の設定データベースを参照する。
- 型・ビット幅の検証はあるが、機種/FW別の対応確認、設定固有の範囲、単位換算は行わない。
- 今回の候補6項目（周期1000 ms、NAV周期1、仰角15°、C/N₀ 30、最低6衛星、
  FIXMODE=2）のKeyID・値・RAM指定を、生成バイト列と再パースで確認した。
- ACK/NAKの表示はあるが、Flash保持・再起動後の反映まで確認する仕組みではない。

## 今回の利用への判断

必要な受信機設定を送信する機能は揃っている。一方、成功アイコンだけで設定が
反映されたと判断するのは不十分。使用時は項目ごとにRAMへ設定し、同じキー・層を
GETして確認する。保存するときはFLASHにも設定し、保存層と再起動後のRAMを確認する。
GUIに入力する値は設定の生の単位であり、例えばスケール0.1の項目は換算が必要。
フィルタ閾値の妥当性は本レビューの対象外であり、実機評価で判断する。
